# 📚 درس مهندسی نرم‌افزار (Software Engineering)

به ریپازیتوری رسمی درس **مهندسی نرم‌افزار** خوش آمدید!  
این ریپازیتوری شامل **اسلایدهای آموزشی، تکالیف تحلیلی، برنامه‌ریزی جلسات و قوانین ارزیابی** این درس است.

مرجع اصلی آموزش، کتاب **Software Engineering: A Practitioner's Approach (ویرایش ۸ و ۹) نوشته پرسمن و مکسیم** می‌باشد.

---

## 🎯 ساختار ارزیابی و پروژه تحلیلی درس

در این درس، هر دانشجو یک **پروژه تحلیلی نرم‌افزاری** (مانند سیستم سفارش آنلاین، رزرو درمانگاه، مدیریت امانات کتابخانه یا سیستم آزمایشگاه) انتخاب می‌کند. همگام با جلسات تئوری، مستندات تحلیلی و مدل‌های مهندسی پروژه به‌صورت هفتگی در قالب فایل‌های Markdown در ریپازیتوری گیتهاب شخصی دانشجویان قرار می‌گیرد.

### ⚠️ قوانین تحویل تکالیف:
* **تحویل هفتگی در گیتهاب:** تمام مستندات تحلیلی باید به‌صورت گام‌به‌گام در گیتهاب شخصی شما کامیت (Commit) و ارسال (Push) شوند.
* **ارزیابی بر اساس Git History:** سابقه کامیت‌های منظم در طول ترم معیار اصلی ارزیابی فعالیت مستمر شماست. ارسال یک‌جای مستندات در انتهای ترم نمره‌ای نخواهد داشت.
